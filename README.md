# Can't Stop Multiplayer
독립 프로젝트: C:\Users\whtls\Can't stop-multiplayer

## 실행
Node.js 20 이상: npm ci → npm start
접속: http://localhost:3000
검증: npm test

## 플레이
온라인은 2–4명이 같은 방 코드로 참가합니다. 방장이 선공과 선공 패널티를 설정하고,
선공 플레이어가 처음 굴리면 시작합니다. 한 화면 모드도 2–4명을 지원합니다.

- 주사위는 약 1.1초에 걸쳐 하나씩 공개됩니다.
- 가능한 숫자를 자동으로 나열하지 않습니다. 보드의 열을 직접 선택합니다.
- 같은 열에서 두 칸 오르려면 두 번 클릭합니다.
- 잘못된 선택은 등반 확인 버튼이 비활성화됩니다. 선택 지우기로 초기화할 수 있습니다.
- 등반 확인을 누를 때 서버가 주사위 분할과 모든 이동 조건을 검증하고 한 번에 적용합니다.
- 두 합 모두 이동 가능하면 둘 다 선택해야 합니다. 한쪽이 막혔으면 한 이동만 가능합니다.
- 멈추면 진행을 저장하며, 세 열을 선점하면 승리합니다.
- 실패한 주사위도 모두 공개된 순간부터 5초 동안 평상시처럼 열을 선택할 수 있습니다.
  5초 뒤 실패를 알리며 임시 말과 주사위가 약 0.9초 동안 함께 떨어집니다.
  저장된 말은 유지됩니다. 이후 다음 플레이어 버튼으로 진행합니다.
- 선택적인 선공 패널티는 선공의 첫 턴에만 임시 말을 2개로 제한합니다.
- 접힌 패널은 차례, 말 표시, 핵심 버튼만 남기고 남는 높이를 채팅에 배정합니다.
- 연속된 같은 발신자의 채팅은 이름과 시간을 한 번만 표시합니다.

## 구조
server.js: Twixt의 Express 정적 서버와 Socket.IO 방별 상태 전달·재접속 구조를 참고.
game.js: 서버 권한 규칙 엔진, crypto 난수, 열 선택 검증.
public/app.js: 보드 선택, 화면 표시, 채팅, 애니메이션.
public/presentation.js: 공개·대기·낙하 시간 규칙.
public/styles.css: Twixt의 남색 패널, 밝은 보드, 플레이어 색상을 참고한 반응형 UI.

게임은 메모리에 저장되며 서버를 재시작하면 초기화됩니다.
접속자 없는 방은 2시간 후 정리합니다. 온라인 재시작은 모두의 동의가 필요합니다.
